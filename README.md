# ECOM EXPO 2026 — сбор участников выставки → Excel

Скрипт собирает экспонентов со страницы [expo.oborot.ru](https://expo.oborot.ru/#schemeplan)
(блок «Список экспонентов») и сохраняет в Excel — **на каждой вкладке компании
своей рубрики**, плюс сводный лист.

## Что собирается по каждой компании
| Поле | Описание |
|------|----------|
| Компания | Название |
| Сайт | Ссылка на сайт компании |
| Стенд | Номер стенда (напр. `G6.9`) |
| Описание | Краткое описание услуг |
| Работа через маркетплейсы | Иконка-признак |
| Собственный канал продаж | Иконка-признак |
| ID экспонента | Внутренний ID (для запроса детальной карточки) |

Рубрики (вкладки): *Доставка и логистика, Маркетинг и продвижение, Платежи и
финансы, Сайт IT и бэкенд, Управление ассортиментом, Управление бизнесом, Другое.*

## Установка
```powershell
pip install -r requirements.txt
```

## Запуск
```powershell
python scraper.py                          # скачать с сайта → exhibitors_ecom_expo_2026.xlsx
python scraper.py --save-html page.html    # ещё и сохранить исходный HTML
python scraper.py --html page.html         # разобрать локальный HTML (без сети)
python scraper.py --group booth_number     # другая группировка вкладок
python scraper.py --out result.xlsx        # своё имя файла
```

Доступные группировки (`--group`): `main_category` (по рубрикам, по умолчанию),
`company_name` (по алфавиту), `booth_number` (по стендам), `serviсe_purpose` (по типу услуг).

## Как это устроено
Все данные присутствуют в статическом HTML страницы — «раскрывающиеся области» это
обычные CSS-аккордеоны. Поэтому **браузер/Selenium не нужны**: достаточно
`requests` + `BeautifulSoup`. На странице есть 4 готовые группировки экспонентов
(`data-scheme-booth-table`), скрипт берёт нужную и раскладывает компании по вкладкам.

## Возможное развитие
- **Детальные карточки.** У каждой компании есть `ID экспонента`; эндпоинт
  `POST /detail/one_exhibitor/` (id) отдаёт расширенную карточку (контакты,
  логотип, полное описание). Можно дозапросить и добавить колонки.
- **Логотипы спонсоров.** Отдельный блок «Экспоненты и партнёры» (≈243 логотипа со
  ссылками и номерами стендов) — можно собрать аналогично.
- **Расписание.** В свежих прогонах фиксировать дату сбора, сравнивать диффы.

## Файлы
- `scraper.py` — основной скрипт (скачивание, парсинг, выгрузка в Excel)
- `requirements.txt` — зависимости
- `page.html` — сохранённая копия страницы (для офлайн-разбора)
- `exhibitors_ecom_expo_2026.xlsx` — результат

## Сайт-разбор выставки

**https://wwwparser.github.io/ecom-expo-2026/** — независимый сайт по ECOM Expo’26,
собранный навыком `expo-site` поверх данных этого проекта.

Разделы: программа конференции (34 секции, 182 доклада с тезисами, фильтры по дню
и залу), участники (205 компаний со стендами, историей участий и соцсетями),
спикеры (156 карточек с био и внешними ссылками), розыгрыши из Telegram-каналов,
архив 2015–2026 (1227 компаний) и четыре авторских разбора.

### Как пересобрать

```powershell
python collect_program.py        # программа и карточки спикеров с expo.oborot.ru
python enrich_speakers.py        # внешние ссылки спикеров через XMLRiver (платно)
python expo_adapter.py           # всё собранное -> data/site/*.json + content/archive.html
python ~/.claude/skills/expo-site/scripts/site_build.py --root . --out site
python ~/.claude/skills/expo-site/scripts/publish.py --repo ecom-expo-2026
```

### Что не публикуется

Почты и телефоны компаний собраны в `contacts_out/` и `archive_contacts_out/`,
но на сайт и в репозиторий не попадают: открытый список рабочих почт — готовая
база для спама. Отфильтрованы и «телефоны под видом ссылок» (`t.me/+7…`),
а почты и номера внутри цитируемых постов маскируются. Эти папки, выгрузки xlsx
и `tg_login_state.json` с личным телефоном — в `.gitignore`.

### Файлы сайта

- `collect_program.py` — программа с главной страницы (дни, залы, секции, доклады, тезисы)
- `enrich_speakers.py` — внешние ссылки спикеров через выдачу, с защитой от однофамильцев
- `expo_adapter.py` — сведение всех источников в контракт навыка `expo-site`
- `content/` — авторские статьи и страницы, `data/site/` — данные для генератора
